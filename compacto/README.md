# alkimia compacta (sin GitHub, en cuenta gratis)

Para quien no quiere pagar Claude o empieza sin GitHub (alkimia, 12 nov; Carlos: «a ver si se puede con el free de GPT… ¿tal vez es el paquete compacto de instrucciones para proyectos?»). Es un solo texto: [INSTRUCCIONES.md](INSTRUCCIONES.md). La versión completa sigue siendo la plantilla de este repo.

## Qué permite hoy cada cuenta gratis (revisado el 12 nov en la documentación oficial)
| | Claude gratis | ChatGPT gratis |
|---|---|---|
| Proyectos con instrucciones propias | sí (límite de proyectos según el plan; revisar en claude.com/pricing) | sí |
| Archivos en el proyecto | sí | hasta 5 por proyecto |
| Conector propio (la puerta de alkimia) | **sí, uno** (Configuración → Conectores → Agregar conector personalizado) | no (los conectores MCP propios son de Business, Enterprise y Pro) |
| Retro | por la puerta (`dejarRetro`) | por correo, con el texto que arma el asistente |

Fuentes: support.claude.com «Get started with custom connectors using remote MCP» y claude.com/pricing; help.openai.com «Projects in ChatGPT» y «Connecting custom MCP servers in ChatGPT».

## Arranque en Claude gratis (recomendado: deja retro sola)
1. claude.ai → Projects → Create project → nombre «mi alkimia».
2. En «Instructions» del proyecto pega el texto de INSTRUCCIONES.md (entre las dos líneas).
3. Configuración → Conectores → Agregar conector personalizado → nombre alkimia, URL: tu enlace personal (te llega aparte). Es el único conector del plan gratis.
4. Abre un chat dentro del proyecto y dile «estado».

## Arranque en ChatGPT gratis
1. chatgpt.com → Projects → New project → «mi alkimia».
2. En las instrucciones del proyecto pega el texto de INSTRUCCIONES.md.
3. Abre un chat en el proyecto y dile «estado». Al cerrar el día dile «retro» y mándalo por correo como te indica.
