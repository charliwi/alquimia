# Retro

El retro lo arma tu agente cada día al cerrar. Cuenta **el cómo, no el qué**: no hace falta contar en qué trabajaste, sino cómo te funcionó trabajar así.

**Dónde:** tu agente lo deja por la puerta de alkimia con la herramienta `dejarRetro`, que lo guarda en una carpeta de nuestro entorno, firmado con tu llave. Si no tienes la puerta conectada o falla, mándalo por correo a carlos@iwi.com.mx con el asunto «Retro alkimia · AAAA-MM-DD».

**Qué no va:** datos tuyos o de tus clientes, nombres, teléfonos, correos, cuentas ni montos. Sólo el cómo y el patrón.

**Nombre:** `retro/AAAA-MM-DD.md`

**Cómo subirlo:** en GitHub, dentro de `retro/`, pulsa **Add file → Create new file**, pega el formato y pulsa **Commit changes**. O pídeselo a tu agente de Claude si le diste acceso a este repo.

**Formato:**

```markdown
# Retro · AAAA-MM-DD

**Qué probé:** <agentes, reglas, conexiones que usé estos días>
**Qué funcionó:** <lo que sí>
**Qué no funcionó:** <dónde se trabó, qué hizo el agente que no esperabas>
**Dato que no cupo en el mapa:** <lo nuevo que apareció y qué faltó para trazarlo>
**Patrón que veo:** <lo que se repite>
**Regla nueva que propongo:** <una, en una línea, o «ninguna»>
**Feedback de producto:** <qué le falta o le sobra al kit>
```
