# Bandeja

Aquí llegan las notas y encargos para este espacio.

**Nombre de cada nota:** `AAAA-MM-DD_de-<quien>_para-<quien>_<tema>.md`

**Forma de cada nota:**

```markdown
# <de> → <para> · <tema>

AAAA-MM-DD. <Aprobado por ... / Propuesta, sin aprobar>

## Qué es
## Qué se pide
## Límites

## Recepción
- [ ] <agente>: <acuse con fecha, qué hizo y dónde quedó>
```

El agente que recibe deja su acuse en «Recepción». Una nota no se borra: se marca como atendida.
